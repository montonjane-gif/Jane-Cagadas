# Enrollment System

A C# Windows Forms desktop app developed as an academic project.

## Overview

This enrollment system was built with C# Windows Forms in Visual Studio. It provides login authentication and administrative student-management workflows across multiple academic programs.

## Features

- Login form with show/hide password
- Hardcoded admin/admin login for demonstration
- Main dashboard with navigation to programs: BSIT, BEED, BSED, BSHM, BSTM, BSC, BSN, BSBA, BPE, BSNED, BSGE
- Student record management per program: add, update, delete, and list view
- Student fields: first name, last name, middle name, birth date, age, gender, address, email, contact number
- Profile picture upload per program
- Logout back to login
