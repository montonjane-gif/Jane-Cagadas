# LookIT

A UI/UX mobile home-security app concept designed in Figma.

## Overview

LookIT is a mobile interface concept for a home-security application. It explores how users might interact with an existing camera and speaker setup through their phone, including controls for monitoring, voice interaction, and handling visitors or deliveries.

## Features

- Mobile-first home-security interface
- Camera and speaker controls
- Voice interaction concepts
- Visitor and delivery interaction flows
- AI-assisted voice concept (design exploration)

## Technologies Used

- Figma
- UI/UX design
- Mobile prototyping
- Interaction design
- Product concept development
