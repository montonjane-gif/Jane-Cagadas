# Simple POS

A Java Swing point-of-sale application created as a final academic project.

## Overview

Simple POS is a desktop GUI app for selecting products, building an order, and calculating totals. It runs as a standalone Java Swing application with in-memory cart handling.

## Features

- Product selection buttons with images
- Quantity counters per product
- Cart table showing ID, item name, quantity, and line total
- Total amount calculation
- Pay and balance calculation
- Receipt preview in a text area
- Delete selected cart row and reset its quantity

## Technologies Used

- Java
- Java Swing
- NetBeans GUI Builder
