# Digital Finance Buddy

A beginner-level front-end budget and expense tracker built with HTML, CSS, and JavaScript.

## Overview

Digital Finance Buddy is a practical web app that helps users track spending against a set budget. It runs entirely in the browser with no backend or database.

## Features

- Set a total budget
- Add expenses with names and amounts
- View total budget, total expenses, and remaining balance
- Edit and delete expense entries
- Basic input validation
- Responsive layout for different screen sizes

## Technologies Used

- HTML5
- CSS3
- JavaScript (DOM manipulation, event handling)

## How It Works

The app stores the budget and expense list in memory. Users enter a budget amount, then add individual expenses. The interface updates totals and remaining balance immediately. Expenses can be edited or removed, and simple validation prevents empty or invalid inputs.

## How to Run

1. Clone or download this repository
2. Open `index.html` in a web browser
3. No build step or server required
